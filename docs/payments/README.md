## Placeholders

- `[owner: …]` and `［待業主填寫：…］` mark facts only the owner has: company details, volumes, dates.
- `[Planning: …]` marks a ruling Planning has to make first. The handoff note `docs/handoffs/PAY-01.md` lists each one.

## Source markers

- **[P]** The provider's own page, or an official law or regulator page.
- **[S]** Secondary: a third-party article, plugin listing or aggregator.
- **[G]** General knowledge, not checked in this session.

This session couldn't open web pages directly, because the environment's network policy blocks them. Every [P] and [S] item was read through search-result summaries. Check each one against the live page before it goes into an application.
