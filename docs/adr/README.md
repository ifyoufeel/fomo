# Decision records

Owner: Planning. One file per decision, numbered `NNNN-short-title.md`.

Chats propose decisions in their handoff notes; Planning records the ones that bind other chats here.

```text
# NNNN Title
Date · Status: proposed / accepted / superseded by NNNN
Context: what forced the decision
Decision: what we chose
Consequences: what follows, good and bad
```
